# 2. ESPAÇAMENTOS E MEDIDAS GLOBAIS
# ==============================================================================
#
# ------------------------------------------------------------------------------
# [PADRÃO 01] ESPAÇAMENTO PADRÃO (DISTÂNCIA PADRÃO TOOLTIP <-> ÍCONE/ELEMENTO)
# ------------------------------------------------------------------------------
# DEFINIÇÃO:
# A "Distância Padrão" corresponde à distância vertical de respiro (gap/clearance)
# entre a face inferior do balão de dica (Tooltip) e a face superior do glifo/ícone
# ou elemento interativo ao qual ele se refere.
#
# MEDIÇÃO TÉCNICA E VALOR OFICIAL:
#   * Valor Nominal: 6 PIXELS (gap = 6px).
#   * Ancoragem na Barra Inferior (Dock/Taskbar):
#       - Posição Y da âncora popup: `rect.y = 12` (em relação ao topo do dockLayer).
#       - Borda inferior do tooltip: repousa no nível Y = 12, ficando nivelada com o
#         topo da caixa de foco do slot (26px) e exatamente a 6px do topo do glifo
#         visual interno (que se inicia em Y = 18).
#   * Ancoragem em Menus/Popups Grid (ex: TrayOverflowPopup):
#       - `anchors.bottomMargin: 6` (6 pixels exatos acima do contêiner do item).
#   * Aplicação:
#       Toda vez que uma nova interface, widget ou popup solicitar a inserção de
#       um tooltip com "espaçamento padrão", deve-se aplicar o gap vertical de 6px
#       em relação ao seu elemento interativo, garantindo zero sobreposição e
#       alinhamento harmônico no eixo Y.
#   * Popups e Janelas acionados por Ícones (Regra de Relatividade Estrita):
#       O Espaçamento Padrão é sempre relativo à posição geométrica do elemento
#       interativo clicado, e NUNCA uma coordenada absoluta global fixa:
#       1. Ícone na Barra Inferior (Dock/Taskbar):
#          - O tooltip do elemento abre nivelado na linha local Y = 12.
#          - O pop-up ou janela de configuração (ex: overflow na setinha, ou
#            painel de áudio/rede fixado) abre com sua borda inferior repousando
#            exatamente nessa mesma linha (gap: -12), centrado no ícone clicado.
#       2. Ícone dentro da Janela Pop-up (ex: Grid do TrayOverflowPopup):
#          - O elemento possui coordenadas próprias na tela (`screenX`, `screenY`).
#          - O tooltip daquele item repousa a 6px acima do contêiner (`bottomMargin: 6`).
#          - A janela de configuração correspondente (áudio, rede, monitor, agentes,
#            clima) deve abrir ancorada A ESSE ELEMENTO ESPECÍFICO, mantendo o mesmo
#            espaçamento padrão relativo (borda inferior em `screenY - 6`, centrada
#            horizontalmente no ícone do grid), e JAMAIS lá embaixo na barra dock.
#       3. Princípio de Ilusão de Expansão:
#          Em qualquer local da interface, o pop-up deve surgir na mesma cota de
#          afastamento do tooltip ativo para aquele item, criando a sensação contínua
#          de que o tooltip se expandiu na janela do aplicativo.
#

# 3. CATÁLOGO DE COMPONENTES E DESIGN TOKENS
# ==============================================================================
#
# ------------------------------------------------------------------------------
# [COMPONENTE 01] TOOLTIP PADRÃO (TASKBAR & POPUPS)
# ------------------------------------------------------------------------------
# Estrutura visual compacta para rótulos de dica rápidos e elegantes:
#   * Tipografia:
#       - Família: Style.font.family
#       - Tamanho: 10px (`font.pixelSize: 10`)
#       - Formato: Text.PlainText
#       - Cor: Color.composed("popups.text", "popups.text-alpha", Color.text, 0.95)
#   * Dimensões e Padding Interno:
#       - Largura: `implicitWidth = bubbleLabel.implicitWidth + 12` (6px em cada lateral, redução de -20% em relação ao modelo inicial).
#       - Altura: `implicitHeight = bubbleLabel.implicitHeight + 8` (4px superior/inferior, redução de -20%).
#       - Raio de curvatura: 4px (`radius: 4`).
#   * Superfície e Fundo:
#       - Fundo Escuro: `color: Util.alpha(Color.popups.background, 0.90)` (90% opacidade / 10% transparência).
#   * Borda e Contorno (Outline):
#       - Espessura: 1px (`border.width: 1`).
#       - Cor e Opacidade: `border.color: Color.composed("popups.border", "popups.border-alpha", Color.outline, 0.40)` (Opacidade de 40%).
#   * Ancoragem e Elevação:
#       - Superfície: PopupWindow nativa do Quickshell (camada Wayland fora do dockLayer) ou Rectangle elevado com z: 9999.
#
# ------------------------------------------------------------------------------
# [COMPONENTE 02] TRAY OVERFLOW POPUP (MENU DE ÍCONES OCULTOS)
# ------------------------------------------------------------------------------
# Dimensões e espaçamentos da janela pop-up que exibe os ícones ocultos da bandeja (^):
#   * Glifo do Ícone (Glyph Size):
#       - Tamanho: 17px (`font.pixelSize: 17`) — rigorosamente idêntico ao tamanho
#         dos ícones fixados na barra de tarefas padrão (`SystemIconTray.qml`).
#       - Família tipográfica: Style.font.family.
#   * Espaçamento Entre Ícones (Item Spacing):
#       - `rowSpacing: 5` e `columnSpacing: 5` (redução de 20% em relação ao padrão
#         anterior de 6px, mantendo valor inteiro de 5px para máxima nitidez de renderização).
#   * Padding Interno do Grid (Card Padding):
#       - `gridPadding: 8` (redução de 20% em relação ao padding original de 10px,
#         resultando em 16px totais no eixo horizontal e vertical).
#   * Dimensões do Slot e Card:
#       - Slot individual: 44x44 px (`radius: 7`).
#       - Card acrílico: `width = (gridCols * 44) + ((gridCols - 1) * 5) + 16`
#                        `height = (gridRows * 44) + ((gridRows - 1) * 5) + 16`
#       - Raio de curvatura do card: 10px (`radius: 10`).
#   * Superfície e Contorno:
#       - Cor de Fundo: `Color.popups.background`.
#       - Borda: 1px, `Color.composed("popups.border", "popups.border-alpha", Color.outline, 0.28)`.
#       - Glow interno: 1px, `Color.composed("popups.highlight", "popups.highlight-alpha", Color.text, 0.08)`.
#
